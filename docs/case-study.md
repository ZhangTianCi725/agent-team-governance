# 案例研究：一个单人运维的 5-Agent 系统踩过的三个坑

> 以下几个案例抽象自一个真实的、单人运维的多 Agent 生产系统（已做脱敏与泛化）。
> 每一个坑都对应 `govern/` 里的一个模块 —— 治理不是设计出来的，是**被事故逼出来的**。

---

## 案例一 · 静默失效：系统"正常运行"了 13 天，产出却是废的

### 现象
一个负责抓取数据的 Agent 挂了，上游 13 天没有新数据。
但**没有任何报错**：定时任务退出码 0、日志打着 ✓、下游消费方照常运行。
直到某天下游的报告"看起来不对"，人工回溯才发现 —— 数据已经陈旧 13 天。

### 根因
系统用**退出码**判断"是否成功"。但"任务跑完了"和"产出的数据是新的"是两个命题。
数据源静默停更 ≠ 任务失败。

### 修法
不再用退出码判断有效性，改用三条**结构判据**：

```python
ReviewCycle(freshness_days=2).review(records)
# 🚩 [freshness] source: 数据落后 13.0 天 > 阈值 2
```

### 防复发（→ 本库 第三层 `review.py`）
- **新鲜度**：`data_date < 今天 − N` ⇒ 判红。
- 同类还有**可达性**（判定式永远不触发）与**键匹配**（用错键查空表）。
- 核心信条：**有效性 ≠ 退出码**。

## 案例二 · 活文件被整份回写：327 行瞬间只剩 191 行

### 现象
一个团队共享的日志文件，在一次写入后从 327 行骤降到 191 行，**丢了 9 个段落**。
同一天，另一个共享文件被写成了 **6.8 MB / 8 万行**的垃圾。

### 根因
- **丢段落**：多个 Agent 并行时，各自"整份覆盖"写入 —— A 读到的是旧快照，
  覆盖时把 B 刚写的内容抹掉了。文件写入的"覆盖保护"是**单进程**级的，挡不住并发。
- **写炸**：用未加引号的 shell heredoc 写入，内容里的反引号和 `$()` 被当成命令**执行/展开**了。

### 修法
对共享活文件，改为**只追加 + 写完自证**：

```python
store.append(record)          # 只追加，绝不整份回写
store._verify_landed(record)  # 回读末行，确认"这是我的这条"
```

### 防复发（→ 本库 第一层 + `store.py`）
- **append-only**：共享文件只允许追加，禁止整份覆盖。
- **写入自证**：写完必须回读确认落地（并发下 `>>` 也可能丢）。
- **回滚要连产物一起清**：源码回滚时，对应的数据快照 / 记录也必须同步处理，
  否则会留下"带着今天时间戳、描述昨天状态"的假新鲜收据。

## 案例三 · 假绿判据：检查永远通过，因为它根本不会红

### 现象
一个健康检查长期显示"全部正常"。后来发现：
- 它的判据**永远不会失败**（正则写死了、或条件恒真）；
- 另一个扫描工具在参数用错时**静默返回空结果** —— 输出与"没有问题"一模一样。

结果：真正的故障被"假绿"掩盖了很久。

### 根因
把"我检查过了"当成了"检查有效"。**一根坏掉的探针，比没有探针更危险** ——
因为它的输出看起来像证据。

### 修法
任何检查上线前，先自证这根探针**能红**：

```python
rs.self_test([
    ("合规样本",     compliant, set()),      # 不该红
    ("违约: 没落盘", bad,       {"R-001"}),  # 必须红
])
```

### 防复发（→ 本库 第二层 `rules.py`）
- **正对照法**：拿一条"必命中"的输入，跑同一条检查命令，它必须命中。
- **正对照 = 0 ⇒ 探针已死**，本次扫描结果作废，不得报"零命中"。
- 同理，"没跑"和"没命中"必须可区分（看退出码 + 错误输出，别把 stderr 吞掉）。

## 三案例 → 三层的映射

| 案例 | 病灶 | 对应层 |
|:--|:--|:--|
| 一 | 用退出码代替有效性 | 第三层 `review.py` |
| 二 | 共享状态被整份覆盖 | 第一层 `decision_log.py` + `store.py` |
| 三 | 检查不会红（假绿） | 第二层 `rules.py` |

> **共同根因**：用一个**未经自证的中间物**（退出码 / 覆盖保护 / 探针）下了结论，
> 而不是用被断言的对象本身。治理的价值，就是把这些"中间物"一个个换成可证伪的判据。
